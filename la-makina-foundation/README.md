# La Makina Foundation

**Live:** [lamakinafoundation.com](https://lamakinafoundation.com)
**Client:** Fundación La Makina, the foundation of MLB pitcher José Berríos
**Role:** Contract developer (Lizardi Technologies), extending an existing Bricks site
**Platform:** WordPress, Bricks Builder, WooCommerce

---

## Overview

La Makina Foundation is a nonprofit that runs youth programs in Puerto Rico and Canada: Challenger Baseball, R.B.I. and Girls At Bat. Its site also supports the **Bayamón Baseball Complex**, with a dedicated page (`/bbc/`) and a donation flow.

The site was already built in Bricks. I was hired to extend it with new sections, forms and content, working inside the existing design system instead of rebuilding it.

## What I did

- **New page sections and blocks** built with custom HTML and CSS inside Bricks, so they match the site's existing look.
- **New forms** for the foundation's visitors.
- **Email setup** so form submissions reach the right people.
- **Images and media:** adding and placing new photography.
- Updates to pages tied to the Bayamón Baseball Complex campaign.

## Why it's here

There's no repository for this one. It's a hosted WordPress site, and the foundation owns the theme and builder. I'm listing it to show real-world work: customizing a page-builder site for a nonprofit with an active fundraising campaign, working inside someone else's design system.
